# 测试与验收

> 本文档是毕业论文「系统测试」一章的素材。所有数字均为本机实测（Windows 11、Python 3.11.9、
> Ollama `qwen3.5:4b` + `bge-m3`），执行命令写在每节标题下，可复现。

## 1. 测试策略

按"能不能自动化"分层：业务规则与边界用单元测试钉住；前端纯函数用 node 回归；连模型与数据库的
链路用手工端到端脚本验收；性能与安全单独记录。

| 层次 | 工具 | 数量 | 覆盖内容 | 是否依赖模型 |
| --- | --- | --- | --- | --- |
| 后端单元 | pytest | 21 | 可见性、门控、限流、分页、并发闸门、提示词装配 | 否（模型用 fake） |
| 前端纯函数 | node + `vm` | 2 | 分页条行为、Markdown 转义与链接白名单 | 否 |
| 端到端 | Python 脚本（urllib） | 4 组 | 登录、列表、问答、拒答、上传入库、检索命中 | 是 |
| 性能 | 计时脚本 | — | 冷/热启动、首 token、整轮耗时、测试套件耗时 | 是 |
| 安全 | 单测 + 用例 | — | XSS、越权、限流、令牌失效 | 部分 |

运行方式：

```bash
python -m pytest            # 全部自动化用例（含 node 脚本）
python -m ruff check .      # 静态检查
```

### 2.1 权限与可见性

| 用例 | 验证点 |

| `test_course_visibility_and_write_guard` | 学生只能看到"公共库 + 自己的库"；能看见 ≠ 能写：公共库对学生 403；空名/不存在库 400 |

### 2.2 RAG 判定（门控）

| 用例 | 验证点 |
| --- | --- |
| `test_course_related_short_circuit` | 只命中课程词 → 直接判相关；只命中无关词 → 直接判不相关；模型不可用时保守判不相关 |
| `test_course_related_ambiguous_asks_model` | 同时命中课程词与"考研/面试"时交给模型判，模型答"是"则放行、答"否"则拒答 |

## 4. 性能实测

| 指标 | 实测值 | 说明 |
| --- | --- | --- |
| 冷启动 → 健康检查可用 | 15.7 s | 首次起进程（磁盘缓存冷） |
| 热启动 → 健康检查可用 | 13.2 s | 其中约 11 s 是 Python 依赖导入 + 种子数据幂等检查 |
| 自动化测试套件 | 13.49 s | 23 个用例（含 2 个 node 脚本） |
| 首 token | 13.2–16.6 s | 4B 本地模型热态 |
| 整轮回答 | 19.7–31.2 s | 与回答长度正相关（97 字 ≈ 20 s，188 字 ≈ 31 s） |
| 上传 700 字 TXT 到可检索 | < 3 s | 解析 + 分块 + 向量化（bge-m3 本地） |

> 优化记录：改造前启动 44–94 s。根因不是业务代码，而是环境里装了一个项目并不使用的
> `sentence-transformers`（连带 `transformers`/`torch`），而 `langchain_text_splitters`
> 的包初始化会无条件导入它。处理方式：卸载该孤儿包 + 把分块器的导入延迟到真正解析文档时。
> 处理后启动稳定在 13–16 s，测试套件从 196 s 降到 13.5 s。

## 5. 安全测试

| 面 | 用例 | 结果 |
| --- | --- | --- |
| XSS | 回答里塞 `<script>alert(1)</script>`、`<img onerror>` | 全部转义为文本 |
| 危险链接 | `[点我](javascript:alert(1))` | 不生成 `<a>`，原样保留为文本 |
| 代码块注入 | 代码块里写 `</pre><script>` | 被转义 |
| 越权（横向） | 学生请求他人私有知识库的知识点 | 403 |
| 越权（纵向） | 学生调用管理员接口 | 403（`require_role`） |
| 令牌失效 | 改密后旧 token 继续访问 | 401（`ver` 不匹配） |
| 限流 | 同一账号/IP 连续失败登录 | 10 次后锁定，返回提示 |
| 文件上传 | 非白名单后缀、超 20 MB | 400 / 413 |
| 默认管理员 | `HOST=0.0.0.0` 且密码未改 | 服务拒绝启动并打印处理步骤 |

## 6. 已知限制与改进方向

| 限制 | 影响 | 改进方向 |
| --- | --- | --- |
| 单进程运行 | 无法横向扩展（序号顶替依赖进程内状态） | 把 `_gen_seq` 落 Redis/DB，改多 worker |
| 拒答阈值依赖具体向量模型 | 换 `bge-m3` 之外模型需重新标定 0.85 | 提供标定脚本，启动时校验 |
| 无 OCR | 扫描版 PDF 取不到文字 | 接 PaddleOCR / Tesseract |
| 4B 模型延迟偏高 | 首 token 13 s 以上，答辩要预热 | 换更大机器、或切 OpenAI 兼容 API |
| 无 API 集成测试框架 | 端到端靠一次性脚本 | 引入 `TestClient` + 固定模型桩，纳入 pytest |
| 遗留表 `message_feedback` | 占位不读写 | 确认后删除 |
