# 演示数据

答辩 / 截图用的演示数据脚本。只写 SQLite，不调用大模型；知识点向量由应用启动时的 `backend.seed` 负责。

## 使用

先按 README 完成 `.env` 配置（至少填 `JWT_SECRET`）。

```bash
# 1. 确保 Ollama 已启动并拉取模型
ollama pull qwen3:8b
ollama pull bge-m3

# 2. 生成演示学生、会话、消息反馈和未命中问题
python demo/seed_demo.py

# 3. 可选：把 20 个种子知识点同步成「文档管理」里的文档记录
python .tools/sync_seed_documents.py

# 4. 启动
python run.py
```

如果数据库里已经有四门课和知识点，可以跳过种子：

```bash
python demo/seed_demo.py --no-seed
```

## 会生成什么

- 4 个学生账号；
- 8 个会话、16 条消息，包含点赞、点踩和一条拒答示例；
- 4 条未命中问题，3 条待处理、1 条已解决。

脚本是幂等的：同名账号、同标题会话、同问题不会重复插入。
